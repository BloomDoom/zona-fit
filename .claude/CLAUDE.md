# Zona Fit

@../README.md

The README above is the index of this repo: read it before any task and use it
to go straight to the right files instead of exploring.

- **Sister project:** `../mama` (Ms Dany's Place, the school app this was built
  from, same architecture). Before building something, check if it already
  exists there; the README's "Sister project" section maps the words and
  shared files.
- **Keep the README current:** when adding a screen, lib file, component,
  table or migration, update the structure, the Screens table and, if it
  changes, the "Sister project" lists.
- Schema changes: update `supabase/schema.sql` (always complete) AND add a
  dated file in `supabase/migrations/`.
- UI text in Spanish; code in English. Dates DD/MM/YYYY, money es-AR.
- Keep it simple: no new dependencies or abstractions without asking.
